# Notes

- `useState()` is used to store and update data that we change in the application. 
- `axios` - it is used to send HTTP requests from the React frontend to the Node.js backend.
- **CSS file** is used to style this react application.
- `App()` defines the main react component called App. Everything displayed by this component appears on the webpage. 
- `setname()` is used to update the name where the user types.
